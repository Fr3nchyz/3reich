# Specs

One markdown file per feature, named `NN-short-name.md`. Say WHAT the feature must do and how we know it is done, not how to build it. Use mermaid diagrams for flows and state. Cite the rules reference (`Ref 12.4`) for anything that comes from the game.

Template:

```md
# Title
## Goal
## Behaviour (what the player or engine does)
## Rules references
## Open questions (also add to docs/RULES.md)
## Done when
```
