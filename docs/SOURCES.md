# Sources

None of these files are stored in this repo (copyright). Download them into a local folder outside the repo, e.g. `~/3reich-research/`, and read them from there.

## Primary: the 1996 PC game

| What | Where | Notes |
|---|---|---|
| **Reference Manual** (48 pp, the rules) | https://www.geocities.ws/kevinpeele/files/manual2.pdf | Searchable OCR. Use `pdftotext` (without `-layout`) for reading order. |
| Reference Manual p.35 corrected scan | https://www.geocities.ws/kevinpeele/files/RefManPg35.pdf | The page in the main scan is defective. |
| **Operations Manual** (40 pp: UI, sequence of play, all 4 scenarios, force pools) | https://www.geocities.ws/kevinpeele/files/manual.pdf | Also at archive.org: https://archive.org/download/retrokit-manuals/pc/pc-original.zip/Third%20Reich%20%28en%29.pdf (42 pp scan). Force pools are pictures of counters, not text. |
| **Errata and PC-vs-board-game differences** | https://www.geocities.ws/kevinpeele/manuals.htm | Overrides the manuals where they disagree. Highest priority. |
| **Reference map card** (300 dpi scan, 2 pages: map front, all charts back) | https://www.myabandonware.com/download/mbl9-third-reich | `Third-Reich_Map_DOS_EN.pdf`, 4458x3458 px per page. Source for the hex map. |

## Fallback only: the board game (4th edition)

Use only where the PC sources are silent, and say so in code comments.

- Amplified 4th Edition rulebook: https://wargameacademy.org/3R4/3R4-rulebook-070908.pdf
- Gamer's Guide to Third Reich: https://wargamer.fr/pdf/the-gamers-guide-to-third-reich-avalon-hill.pdf
- BoardGameGeek files (4th ed. rules, maps, aids): https://boardgamegeek.com/files/thing/1563
- VASSAL 4th-edition module: https://vassalengine.org/library/projects/Rise_and_Decline_of_the_Third_Reich_4th_Edition
